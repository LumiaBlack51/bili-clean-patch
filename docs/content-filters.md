# 0.4.0 首页与竖屏净化

适配固定原包 Bilibili 9.12.0（9120300），保留 0.3.1 的全部播放器迁移与定时关闭修复。沿用原签名，可覆盖安装已有 BiliClean 补丁版。

在「去广告与空降助手」设置中加入三个独立开关，首次升级默认全部开启：

- **隐藏首页横幅**：移除推荐顶部 `banner` / `banner_v*` 卡片，包括运营横幅。关闭后刷新首页恢复；横幅不受通用广告开关二次拦截。
- **屏蔽创作推广**：首页按推荐理由“创作推广”识别；竖屏流过滤推广理由、广告标记及宿主识别的竖屏广告类型。保留 `is_ad=false` 的普通占位对象。关闭后重新进入推荐流恢复；通用首页广告过滤仍由原有开关控制。
- **隐藏会员购**：过滤首页/竖屏中的会员购链接卡片，把底部“会员购”原位置替换为齿轮图标的“设置”，点击直接打开原生设置页，返回后保持原先首页位置。兼容网络返回及本地缓存/默认导航模型。关闭并重启后恢复会员购入口。大会员入口保持正常。

三个新开关不依赖「过滤界面广告」总开关。普通视频标题、描述含“创作推广”或“会员购”不会触发删除；会员购链接按 URI 主机匹配，不使用任意字符串包含匹配。未适配的新广告形态、个人页及内嵌网页入口不保证全部覆盖。

## 实现和验证方法

- 首页继续使用现代 Gson 传输解析与旧解析入口。匹配真实 `BasePegasusData` 接口和宿主的推荐理由读取方法。
- Story 在 `StoryFeedResponse.Data.getItems()` 返回处过滤，覆盖不同反序列化入口，保留源列表供关闭开关后恢复。
- 导航除 JSON 入口外，包装原生 `MainResourceManager` 的五个列表入口及默认底部列表入口。修改副本，保留缓存源模型用于关闭恢复；在原生底部点击处理前打开设置，避免改变当前选中页。
- `ContentFilterTest` 在实际宿主进程内构造真实 Gson 首页模型、Fastjson Story 模型，遍历八种开关组合、验证广告占位保留、会员购/大会员区分、相似域名保留、原生导航入口及安装包内 Story getter hook。`NavigationTest` 从实际首页点击底部设置按钮，核对打开的 Activity 及返回后的选中页。受控数据通过不等于线上所有广告样本都已出现并验收。
- 交付前回归宿主广告、手势、首页迁移、定时关闭与空降测试，结果见本页末尾和 `evidence/content-0.4.0-*.txt`。

APK、SHA-256 和 manifest 随 GitHub Release 提供；本地原包、签名密钥、测试设备截图及账号数据不上传。
