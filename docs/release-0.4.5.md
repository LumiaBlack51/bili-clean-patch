# BiliClean 0.4.5 · 双击跳转动画与触感

双击快进/后退不再弹出底部 Toast，改为播放器对应侧的半透明弧面、方向箭头和秒数动画。同方向在 1.2 秒内继续双击时累计显示 10、20、30、40 秒，换方向或停顿后从 10 秒开始；最后一次操作后淡出。每次有效跳转附带一次短促系统触感，尊重系统设置，中央双击及没有移动的操作不触发。

入口：设置 → 去广告与空降助手 → **YouTube 风格手势**。开关仍默认关闭。支持当前固定宿主 `tv.danmaku.bili` 9.12.0 (9120300)，ARM64；使用原有签名，可覆盖更新并保留数据。

验证：完整构建、核心策略测试和签名验证通过；最终 APK 在 Android 36.1 AVD 通过 67 项播放器检查和 25 项开屏回归。随后在小米 13 Pro / Android 16 验证横竖屏双向连续跳转、累计动画、暂停状态、中央和关闭开关无新增反馈；系统振动服务确认有效操作执行 `SEGMENT_TICK`，关闭系统触感时请求被拦截。真机安装包哈希与发布 APK 一致。

测试限制：AVD 首轮一次真实双击没有位移，同一 APK 复测通过，未确定首轮原因；Story 迁移测试因通知/推荐卡片前置条件未取得有效验收，本次迁移实现未修改。Android 14 以下的触感回退未在真机验证，触感强弱需用户体验。详见 [完整测试记录](test-record.md#045-双击跳转动画与触感2026-10-05) 和 [脱敏小米汇总](../evidence/seek-feedback-xiaomi-0.4.5.json)。
