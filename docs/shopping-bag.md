# 0.4.6 购物袋视频过滤

设置 → 去广告与空降助手 → **屏蔽购物袋视频**，默认开启，可独立关闭。按用户最终选择，过滤竖屏推荐中所有带购物袋入口的视频，包含正常内容附带购物袋的情况，不进行「纯广告」语义判断。没有购物袋的普通文字链接、视频标题、简介、评论、UP 主或 BV 号不作为匹配条件。

## 宿主识别

固定原版 9.12.0 的 `StoryDetail` 将 `story_cart_icon` 解析为 `CartIconInfo`。原生入口使用 `icon_url`、`icon_text`、`icon_title` 展示图标及文案，`uri` 是跳转地址，`goto` 是入口类型。

这个模型也服务于游戏、会员等导流入口，不能只检查对象非空。本规则先调用宿主 `CartIconInfo.isValid()`，再检查宿主购物类型 `goto=cart`，或结构化入口标签 `icon_text=购物`（忽略首尾空白）。不检查视频正文、标题、商品名、任意 URL、图片文件名或完整标题中的「购物」字样。空对象、缺失图标/标签/标题的无效入口，以及游戏/会员/音乐等非购物入口保留。未知类型只有明确显示「购物」标签时才命中。

购物入口与广告标记 `is_ad`、`cm_mark`、`nature_ad` 不同，所以原版认定为普通 UGC 的视频也可能带有效购物袋；新开关专门覆盖这一情形。

## 范围与恢复

- 作用于已接入的 Story 竖屏推荐列表 getter。没有增加对播放权限、搜索、收藏或视频链接的全局拦截。
- 关闭后重新进入竖屏流；缓存源列表不被删除，getter 可重新返回购物视频。
- 既有广告、创作推广、小火箭、课程等开关仍独立生效，关闭购物袋开关不会解除其他规则。
- 首页卡片未验证存在相同的购物袋模型，故没有把广告、任意商品链接或会员购入口冒充为本规则覆盖。
- 未捕获用户截图当次的原始推荐响应，不能保证服务端此后所有购物入口样式都具有上述字段。
- 没有按 `BV1zJHK6gEJn`、UP 主或产品类别写入永久名单。
