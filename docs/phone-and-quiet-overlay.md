# 真机设置核对与观看提示收起（2026-09-24）

## 真机定位

连接的 OPPO PLQ110 安装包与 0.2.1 发布资产 SHA-256 一致，版本为 9.12.0。通过视频内实际设置界面读取到：1047 期开场、片尾均为“仅显示”，赞助为“跳过一次”。“仅显示”只绘制标记，不显示跳过按钮；这解释了本次手机现场的表现。

通过正常 UI 将开场改为“手动跳过”，强制停止并重开视频后，片段详情仍为“手动跳过”。原有 0.2.1 APK 在手机上随即出现开场按钮，点击后原生进度显示约 00:09。片尾同样出现“跳过鸣谢/结束画面 → 18:21”。本次未复现设置保存失败，不能确定用户先前的选择为何与当前设置不同。

按用户已有偏好，已在手机 UI 将无偿/自我推广、三连、开场、片尾、回顾、填充、离题、非音乐部分设为手动跳过。赞助保留自动跳过一次；全片标签与精彩时刻保留仅显示。没有清除应用数据，也没有操作账号、私信或下载。

手机界面和设置检查的原始截图仅保留在 gitignored 的 `local/`，不上传包含登录态界面的原始截图。测试 instrumentation 仍只用于 AVD。

## 提示交互修改

旧版“空降助手 · 几处标记”常驻视频画面，确实影响观看。现在将片段详情入口与原生播放控件同步：轻点视频显示控件时才出现，控件收起或淡出后隐藏。只有展开的原生进度条可触发入口，收起状态的细进度条不会触发。详情页分类标签与进度条颜色继续保留。

手动跳过按钮独立于详情入口：进入设为手动的区间时显示，离开后隐藏，不要求先呼出播放控件。空降关闭、切换视频和离开播放器的清理行为保持。

`AirbornePlaybackTest` 新增横竖屏正常播放下不显示入口、呼出控件出现入口、控件自动隐藏后入口同步消失的验证，继续验证 1047 期的手动跳过和浮层恢复。
