# 0.3.1 首页播放迁移与共用定时菜单修复

目标仍为 `tv.danmaku.bili` 官方 9.12.0 (9120300) 的静态补丁，同证书覆盖更新。

## 修复内容

- 首页推荐可以先打开 Story 竖屏页，再进入 Theseus 详情页。宿主可能复用已准备好的播放器，也可能重新创建播放器；只在 `onPrepared` 捕获 Activity 会漏掉前一种迁移。现在通过已挂载的原生播放视图确认所属窗口，在播放时钟和 Activity 恢复时重新绑定。暂停迁移也会短暂等待视图挂载，非播放页面不会接管播放器。
- 忽略宿主传入空播放器的合成时钟通知，避免清空有效媒体引用。手势区域及中央按钮定位使用屏幕坐标，计入窗口偏移。
- 手机实际的“定时关闭”使用 `TimingReminderSelectDialog`，0.3.0 只适配了旧 `Du0.c` 和全屏定时控件。现在共用菜单也增加“播放到当前视频结束”，跟随原生列表刷新并保持唯一选中状态。
- 原生“不开启”、分钟倒计时和自定义时间取消播完关闭。播完关闭继续依赖完成事件，在自动连播处理前关闭当前播放页；暂停不消耗倒计时。
